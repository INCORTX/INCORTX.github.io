A · Analog vs Digital
🎯 Why does this matter?

The real world

Sound is a continuous curve — infinite detail at every instant.

A computer

Finite memory — it can only store a limited set of numbers.

A computer can't store infinite detail — so we must choose how often to look, and how finely to measure.

→

Those two choices are sampling and quantizing.

1 /
A · Analog vs Digital Where it comes from: two steps, two losses
⏱

Gap between samples = detail lost in time.

📏

Gap between levels = detail lost in value.

Both steps drop information — the skill is keeping what matters.

💻 LAB — Sample a Continuous Signal
①Take a 5 Hz cosine
②Sample it at fs = 50 Hz
③Look at the discrete sequence x[n]

import numpy as np
f, fs, dur = 5, 50, 1              # 5 Hz signal, sample at 50 Hz
n = np.arange(0, dur*fs)
x = np.cos(2*np.pi*f*n/fs)         # digital sequence x[n]
print(x[:8].round(2))             # first 8 samples
🎚️

Sampling turns a continuous wave into a list of numbers x[n] — discrete in time.

B · Sequences & Basic Signals 🔍 Explore — Build a Rectangular Pulse

A pulse is a step that turns on, then off — sweep its width:

explore.py
for N in [2, 3, 4]:
    pulse = ((n >= 0) & (n < N)).astype(int)

🔎

A width-N pulse = u[n] − u[n−N]: it is 1 for N samples, then back to 0.

Any signal splits into an even + an odd part:

xe = (x + x[::-1]) / 2             # even part

1 /
D · Signal Energy & Power Energy = sum of squared values
E=n∑​∣x[n]∣2
💡

Squaring makes every contribution positive — so opposite-sign samples don't cancel out.

1 /
D · Signal Energy & Power Power = average energy per sample
P=E/N

Energy

Total — the whole squared sum. Best for short, finite signals.

Power

Average — energy shared over N samples. Best for long / endless signals.

♾️

An endless signal has infinite energy — so we describe it by power instead.

🔊

🔗

D · Signal Energy & Power
💻 LAB — Compute Energy & Power
①A short sequence x[n]
②Energy = Σ x[n]²
③Power = Energy / N
energy.pyE = Σ|x[n]|²
import numpy as np
x = np.array([1, -2, 2, 0])
energy = np.sum(x**2)              # E = sum of squares
power  = energy / len(x)          # P = E / N
print("energy:", energy, "power:", power)
🔋

Energy sums the squared samples; power is that energy spread over the length.

✔Answer — Analog vs Digital
B) the amplitude axis

Quantizing rounds each sample's value to the nearest level — it divides the amplitude axis (horizontal lines). Sampling divides the time axis (vertical lines).

❌ Common mistake: thinking both steps act on time. Sampling picks when to measure; quantizing decides how finely to record each value.

🧮Worked Example — Signal Values

Write the values of each signal at n = 0..4. The tricky one is the shifted step u[n−3] — build it first, then subtract:

signaln=01234
δ[n]10000
u[n]11111
n−3 (argument)−3−2−101
u[n−3]00011
u[n]−u[n−3]11100
🔎

u[n−3] is u[n] delayed by 3 — it equals 1 only when the argument n−3 ≥ 0 (i.e. n ≥ 3). A negative argument gives 0, so it stays 0 at n = 0,1,2.

📦

The result u[n]−u[n−3] is a pulse — a signal that is 1 over a finite window (here n = 0,1,2), then back to 0. Compare the three: impulse = 1 at a single point · step = 1 forever · pulse = a step turned on, then off.

🧮Worked Example — Building a Pulse

A pulse is a step minus a delayed step. Watch where they overlap:

Subtract term by term:

n01234
u[n]11111
− u[n−3]00011
= pulse11100
💡

Where the two steps overlap (n ≥ 3), 1 − 1 = 0 — they cancel. Only n = 0,1,2 survive → a width-3 pulse.

❌

u[n−3] turns on at n=3, not n=2 — that sets the pulse width.

🧮Worked Example — Time Shift

Given: x[n] = [3, 1, 4, 1] at n = 0..3

Find: y[n]=x[n−1]

Step 1shift each value one step right
Step 2n=1→3, n=2→1, n=3→4, n=4→1
∴ y = [_, 3, 1, 4, 1], starting at n = 1
💡

In a fixed-length array (NumPy), a right shift fills the empty front slot with 0 and drops whatever is pushed off the end: [3,1,4,1] → [0,3,1,4]. Writing [_,3,1,4,1] instead just keeps that last value by letting the index range grow.

🧮Worked Example — Time Reversal (Folding)

Given x[n], find y[n]=x[−n]:

givenx[0]=2, x[1]=5, x[2]=3
foldy[n]=x[−n] reflects about n=0
ready[0]=2, y[−1]=5, y[−2]=3
y = [3, 5, 2]  (n = −2,−1,0)
❌

Common slip: reversing the wrong way — the sample at n=1 moves to n=−1, not n=+1.

💡

Any signal splits into an even part (mirror-symmetric, x[n]=x[−n]) plus an odd part (anti-symmetric). This split makes many later tools — like Fourier analysis — much simpler.

See the split: x[n] = even[n] + odd[n]

📐

even=2x[n]+x[−n]​
odd=2x[n]−x[−n]​

n even=2x[n]+x[−n]​ odd=2x[n]−x[−n]​
−121+3​=221−3​=−1
024+4​=424−4​=0
123+1​=223−1​=1

import numpy as np
# Q2: x2 = np.array([4, 2, 0, 1])

✔Answer — Q4

x2 = np.array([4, 2, 0, 1])
shifted = np.zeros_like(x2)
shifted[2:] = x2[:-2]   # [0 0 4 2]
x3 = np.array([1, 0, 2])
y  = np.array([3, 1, 1])
z  = 2*x3 + y                # [5 1 5]
print(shifted, z)

output

[0 0 4 2] [5 1 5]

matches Q2 & Q3 ✓

⚠️ A true delay zero-fills the front and drops the tail → [0 0 4 2]. np.roll(x2, 2) would wrap the tail back to the front → [0 1 4 2] (circular shift), not a delay.
