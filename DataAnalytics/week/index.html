Every Assignment, Step by Step

The same cycle runs for all six assignments. This page is everything you need each week; the details are on Rules & Marking.

01One cycle

In session N45-minute demo, then your hour on your group’s topic: Question → EDA → Insight → Issue → Solution → Metric. Hand in the notebook as it stands when the hour ends.
At homeFinish the notebook, make 10+ slides, record a 5+ minute video in which every member speaks, write a README. Hand in all four files two days before session N+1.
Start of session N+1Two representatives present for four minutes from the notebook you handed in — no slides — then take questions about your code and your work.

Session 1 has no presentation hour, so its work block is 120 minutes. Assignment 6 is presented briefly at the end of session 6 itself, and handed in like the others.

02Hand in four files, named by the rule

FileFormat
Notebook.ipynb — in Colab: File → Download → .ipynb
Video, 5+ minutes.mp4 (or .mov)
Slides, 10+ pages.pdf or .pptx
README.md or .txt — data source, anything borrowed, where you used AI

Name each file DA_ID_SLOT_Topic.ext — ID is your group (GA–GJ) or your 8-digit student ID if you work alone; SLOT is the assignment, R1–R6.

Group B, assignment 2: DA_GB_R2_HousePriceRegression.ipynb · DA_GB_R2_HousePriceRegression.mp4 · DA_GB_R2_HousePriceRegression.pdf · DA_GB_R2_HousePriceRegression.md

Files, uploaded to Google Classroom — never links. A link, a late file or a wrongly named file counts as not handed in.

03What is marked

  1. Presenting, at the start of the next session
  2. Answering questions
  3. Handing in every file on time
  4. The video — fluent, and it analyses something
  5. The slides — visualisation that is worth looking at
  6. The homework checklist, complete
  7. Length and duration

You are not required to get a good result. A model that loses to its own baseline scores just as well, if you can say why.
