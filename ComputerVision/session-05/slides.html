A · Attention

A convolution uses the same weights for every image

a dog or a bicycle: once trained, a kernel is the same 9 numbers for every photo and every place

Session 4 A and C: a neuron's weights are fixed after training; stacked 3 × 3 layers see 3 → 5 → 7 pixels.

Two limits: the weights do not depend on the picture, and one layer sees only its neighbours.

Session 4 ended with a question: what if every pixel could look at every other? Attention computes its weights from the picture itself — and looks everywhere in one layer.

🇹🇭 ตอบคำถามท้ายคาบ 4 (หน้า 44) · ย้ำสองข้อจำกัด: weight ตายตัว และมองแค่เพื่อนบ้าน

🇬🇧 Answer session 4's last slide (44). Two limits: fixed weights, and only neighbours.

A · Attention

Attention: weights computed from the data

Query qWhat this token is looking for — like the question you bring to a library.
Key kWhat each token offers — the label on each shelf. Match: score = q · k.
Value vWhat each token hands over — the books on that shelf. Output = Σ weight × v.

Every token (a word, or a patch of a photo) makes all three from its own numbers, with learned matrices: q = WQx, k = WKx, v = WVx.

$$\text{score}_j = q \cdot k_j \qquad \text{out} = \sum_j w_j\, v_j$$

The matrices are learned once; the weights wj are computed anew for every picture — that is the difference from a kernel.

🇹🇭 เปรียบห้องสมุด: query = คำถาม · key = ป้ายชั้น · value = หนังสือ · ย้ำ: W_Q W_K W_V เรียนครั้งเดียว แต่ weight ของ attention คำนวณใหม่ทุกภาพ

🇬🇧 Library picture: query = your question, key = shelf label, value = the books. W_Q, W_K, W_V are learned once; the attention weights are computed anew for every picture.

A · Attention

Which tokens does this one listen to?

Four tokens, each with a key (arrow) and a value (a colour). The query is the black arrow.

Score = q · k: large when the query points the same way as a key. Softmax turns scores into weights; the output is the weighted mix of the values — the swatch.

Longer query → sharper weights: one token wins. Length 0 → all equal (0.25 each).

🇹🇭 ลาก direction ไปหาลูกศรแต่ละสี ให้เห็นสีผสมเปลี่ยน · ลาก length: ยาวขึ้น = เลือกขาดขึ้น (ปูทางหน้า 7 หาร √d)

🇬🇧 Turn the query towards each arrow; watch the mix change. Lengthen it: the choice gets sharper (sets up slide 7's ÷ √d).

A · Attention

Softmax turns scores into weights that sum to 1

scores under the bars · weights above them · each set sums to 1

$$w_j=\frac{e^{s_j}}{\sum_i e^{s_i}}$$

Positive, sum to 1, the largest score gets the most — but not all.

With long vectors (d = 64 numbers per key) the scores get large and softmax picks one token only. So scores are divided by √d first: here d = 2, and the weights spread out.

🇹🇭 คิดเลขกับห้อง: e¹ e² e³ = 2.7 7.4 20.1 รวม 30.2 → 0.09 0.245 0.665 · ข้อสอบไม่ให้คำนวณ softmax เอง — ให้ weight มา

🇬🇧 Work it with the room: e¹, e², e³ = 2.7, 7.4, 20.1, total 30.2 → 0.09, 0.245, 0.665. The exam gives the weights; no softmax by hand.

Each of N tokens scores all N: an N × N table of weights, in every layer.

Double the tokens, four times the work. That is why a Vision Transformer does not attend pixel by pixel — part B cuts the photo into patches first.

A · Attention

Try it: attend over three tokens

Try itA query q = [1, 2] meets keys k₁ = [1, 0], k₂ = [0, 1], k₃ = [1, 1].
  1. Compute the three scores q · k.
  2. Softmax gives weights [0.09, 0.24, 0.67]. With values v₁ = [1, 0], v₂ = [0, 2], v₃ = [2, 2], what is the output?
Answer1. 1·1 + 2·0 = 1 · 0 + 2 = 2 · 1 + 2 = 3 · 2. 0.09·[1, 0] + 0.24·[0, 2] + 0.67·[2, 2] = [0.09 + 1.34, 0.48 + 1.34] = [1.43, 1.82] — mostly v₃, the best-matching key.

score = q · k (multiply matching numbers, add).

output = Σ weight × value.

🇹🇭 ให้เวลา 2 นาที · แบบข้อสอบ Final (ให้ weight มา ไม่ต้อง softmax เอง)
