A · Attention

A convolution uses the same weights for every image

a dog or a bicycle: once trained, a kernel is the same 9 numbers for every photo and every place

Session 4 A and C: a neuron's weights are fixed after training; stacked 3 × 3 layers see 3 → 5 → 7 pixels.

Two limits: the weights do not depend on the picture, and one layer sees only its neighbours.

Session 4 ended with a question: what if every pixel could look at every other? Attention computes its weights from the picture itself — and looks everywhere in one layer.

🇹🇭 ตอบคำถามท้ายคาบ 4 (หน้า 47) · ย้ำสองข้อจำกัด: weight ตายตัว และมองแค่เพื่อนบ้าน

🇬🇧 Answer session 4's last slide (47). Two limits: fixed weights, and only neighbours.

A · Attention

Attention: weights computed from the data

Query qWhat this token is looking for — like the question you bring to a library.
Key kWhat each token offers — the label on each shelf. Match: score = q · k.
Value vWhat each token hands over — the books on that shelf. Output = Σ weight × v.

Every token (a word, or a patch of a photo) makes all three from its own numbers, with learned matrices: q = WQx, k = WKx, v = WVx.

$$\text{score}_j = q \cdot k_j \qquad \text{out} = \sum_j w_j\, v_j$$

The matrices are learned once; the weights wj are computed anew for every picture — that is the difference from a kernel.

🇹🇭 เปรียบห้องสมุด: query = คำถาม · key = ป้ายชั้น · value = หนังสือ · ย้ำ: W_Q W_K W_V เรียนครั้งเดียว แต่ weight ของ attention คำนวณใหม่ทุกภาพ

🇬🇧 Library picture: query = your question, key = shelf label, value = the books. W_Q, W_K, W_V are learned once; the attention weights are computed anew for every picture.

Which tokens does this one listen to?

Four tokens, each with a key (arrow) and a value (a colour). The query is the black arrow.

Score = q · k: large when the query points the same way as a key. Softmax turns scores into weights; the output is the weighted mix of the values — the swatch.

A · Attention

Softmax turns scores into weights that sum to 1

scores under the bars · weights above them · each set sums to 1

$$w_j=\frac{e^{s_j}}{\sum_i e^{s_i}}$$

Positive, sum to 1, the largest score gets the most — but not all.

Worked example · scores 1, 3, 0

e¹ = 2.72 · e³ = 20.09 · e⁰ = 1 → sum 23.80 → weights 0.114 · 0.844 · 0.042

With long vectors (d = 64 numbers per key) the scores get large and softmax picks one token only. So scores are divided by √d first: here d = 2, and the weights spread out. Why √d: next slide.

🇹🇭 คิดเลขกับห้อง: e¹ e² e³ = 2.7 7.4 20.1 รวม 30.2 → 0.09 0.245 0.665 · ข้อสอบไม่ให้คำนวณ softmax เอง — ให้ weight มา

🇬🇧 Work it with the room: e¹, e², e³ = 2.7, 7.4, 20.1, total 30.2 → 0.09, 0.245, 0.665. The exam gives the weights; no softmax by hand.

A · Attention

A dot product of d numbers spreads like √d

q · k for 20,000 random pairs of vectors, every entry with mean 0 and variance 1 · measured spread (standard deviation)

Session 3, slide 16: variances of independent values add.
$$q\cdot k=\sum_{i=1}^{d} q_i k_i,\qquad \operatorname{Var}(q_i k_i)=1$$

d independent terms of variance 1 → variance d → spread √d. Divide by √d and the spread is 1 for every d.

Worked example · d = 16, spread √16 = 4

scores 0, 12 → softmax 0.00001 · 0.99999 (one token only) · ÷ 4 → 0, 3 → 0.047 · 0.953

🇹🇭 ที่มา √d: q·k เป็นผลรวม d พจน์ แต่ละพจน์ variance 1 → variance รวม d (ย้อนคาบ 3 หน้า 16: variance บวกกัน) → กระจาย √d · ชี้ภาพ: d 64 กว้าง 8 เท่า หารแล้วกลับมาแคบ · ตัวอย่าง: ไม่หาร softmax เลือกตัวเดียว

🇬🇧 Where √d comes from: q·k is a sum of d terms of variance 1 → variance d (session 3 slide 16: variances add) → spread √d. In the picture d = 64 is eight times wider; divided, it is narrow again. Undivided, softmax picks one token.

C · Learning without labels

The cosine falls out of the law of cosines

a triangle made of two embeddings and the gap between them

The side a − b, two ways. Geometry (law of cosines):

$$\lVert a-b\rVert^2=\lVert a\rVert^2+\lVert b\rVert^2-2\lVert a\rVert\lVert b\rVert\cos\theta$$

Algebra: (a − b) · (a − b) = ‖a‖² + ‖b‖² − 2 a · b. The two agree only if

$$a\cdot b=\lVert a\rVert\,\lVert b\rVert\cos\theta$$

Length 1: ‖a − b‖² = 2 − 2 cos θ, so nearest = largest cosine (session 6 C matches by distance).

Worked example · the triangle on the left

‖a − b‖² = 2 · ‖a‖² = ‖b‖² = 5 → 2 = 10 − 10 cos θ → cos θ = 0.8 · check: a · b ÷ 5 = 4 ÷ 5 = 0.8

🇹🇭 ที่มาสูตร cos: ด้าน a − b คิดสองทาง (กฎ cos ของสามเหลี่ยม · กระจาย dot product) → a·b = |a||b|cos θ · ความยาว 1: ระยะ² = 2 − 2cos → ใกล้สุด = cos มากสุด (คาบ 6 C ใช้ระยะ) · ตัวอย่างบนภาพ: 0.8

🇬🇧 Where the cosine formula comes from: the side a − b two ways (law of cosines; expanding the dot product) → a·b = |a||b|cos θ. At length 1, distance² = 2 − 2cos, so nearest = largest cosine (session 6 C uses distance). The triangle gives 0.8.

C · Learning without labels

Cosine similarity compares directions

$$\cos\theta=\frac{a\cdot b}{\lVert a\rVert\,\lVert b\rVert}$$

1 = same direction · 0 = unrelated · −1 = opposite. Make b longer: the cosine does not move — only the direction counts.

Embeddings are usually normalised to length 1 first; then the cosine is just the dot product a · b. Example: [3, 4] · [4, 3] ÷ (5 × 5) = 0.96.

🇹🇭 ลากมุม 0 → 90 → 180 (cos 1 → 0 → −1) · ลาก length: cos ไม่เปลี่ยน · ย้ำ normalize แล้ว cos = dot product (ข้อสอบ Final)

Try it: which picture is closest?

Try itThree normalised embeddings: query a = [0.6, 0.8], b = [0.8, 0.6], c = [−0.6, 0.8].

A batch of N photos with their N captions gives an N × N table of cosines. The loss pulls the diagonal (true pairs) up and pushes everything else down.

That is part C's contrastive learning — with a caption as the second view. CLIP was trained on 400 million photo–caption pairs collected from the internet.

D · CLIP & zero-shot

The loss: every row is a softmax over the captions

the cat photo's row of the table on slide 34 (CLIP's cosines), true caption in red

Slide 7: softmax · session 4 B: a loss is one number to make smaller.
$$\mathcal{L}_i=-\log\frac{e^{\cos(I_i,T_i)/\tau}}{\sum_j e^{\cos(I_i,T_j)/\tau}}$$

−log of the true caption's share: 0 when it takes everything. Columns too (caption → photo), averaged. τ is learned and ends at 0.01: × 100 — cosines sit in a narrow band, 0.15–0.34.

Worked example · the cat row

× 100: 27.4 vs 21.7 → share 0.995 → loss 0.005 · without × 100: 0.212 → 1.55 · untrained, all equal: 1/5 → log 5 = 1.61

🇹🇭 ที่มา loss ของ CLIP: แต่ละแถว = softmax ของ cos/τ แล้ว −log ของคู่จริง (ย้อนหน้า 7 softmax · คาบ 4 B loss) · ทำทั้งแถวและคอลัมน์ · τ = 0.01 คือ ×100 · แถวแมว: loss 0.005 · ไม่คูณ 100: 1.55 · ยังไม่ train: log 5 = 1.61

🇬🇧 CLIP's loss: each row is a softmax of cos/τ, then −log of the true pair (back to slide 7 and session 4 B). Rows and columns both. τ = 0.01 is the × 100. Cat row: loss 0.005; without × 100: 1.55; untrained: log 5 = 1.61.

To classify, write the classes as sentences, embed them, and pick the sentence with the largest cosine — no training, no new head.

CLIP multiplies the cosines by 100 before softmax (slide 35), so a small lead (0.28 against 0.22) becomes 99.5%.

D · CLIP & zero-shot

What CLIP gets wrong

Counting. 4 elephants. Top answer: “three elephants” (0.33); “four” comes 4th. No answer gets even half the probability.

Text in the picture. A paper note on the apple: “an iPod” 0.92, “an apple” 0.08. It reads words better than it sees fruit.

Bias from the data400 million internet captions carry who is photographed, by whom, and with which words. CLIP learns those patterns too — session 8 D measures them.

Session 5 · what to remember

From fixed windows to learned attention — and open names

  1. Attention: score = q · k, softmax → weights, output = Σ w v; every token sees every token (N²).
  2. ViT: 16 × 16 patches → tokens (224 → 196 + [CLS]); add positions; attention + MLP with skips.

  4. CLIP: photos and sentences in one space; a prompt is a classifier — mind the wording and the limits.
