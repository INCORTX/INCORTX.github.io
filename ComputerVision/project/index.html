📷 Computer Vision · Session 0 › Project Brief

Course Project — 30 points

Replaces the final exam · same group as your presentation rounds (1–3 people) · proposal 14.5 + results, code & demo 15.5

🎯 What the project is graded on: experiment design, how you evaluate what you built, your analysis, and your ideas and creativity — not on how good the numbers turn out. A solution that scores poorly but is compared well and explained is worth more than a pretty number nobody can trace.

1. The task

Pick one real image or video set, propose two or three solutions that take different routes, actually run every one of them, measure on both axes, and pick the best trade-off:

real images / video → preprocessing → solution A / B / C (feature–geometry · CNN · detection …) → accuracy + speed / resources → pick the best trade-off

Must have:

  • Four techniques in use — from the course or from the literature, but every one explained in full, in your own words: the theory · what it does for this project · an example figure (e.g. “median filter because the noise is salt-and-pepper”, not “because the sample code had it”)
  • Two or three solutions — each with its own workflow, plus pros and cons
  • Measured on two axes — accuracy (a metric that fits the task, the same one for every solution on the same data) and speed / resources (time, memory or parameter count, as numbers)
  • Results need not be good — the points are for the idea, the comparison, and the analysis of why things came out the way they did

Data you can use — shoot your own, or an open dataset: everyday photos / panoramas · CCTV / traffic cameras · medical images (X-ray, retina, MRI) · satellite / drone imagery · production-line images (defect checks) · agriculture (leaves / produce) · handwriting / documents

3. Sample Q&A (prepare for these)

Proposal session
  • Why these four techniques — and where did each one come from (which session, which paper)?
  • What really separates solution A from B? If they tie, which do you pick?
  • What about this dataset needs care before you use it?
Results session
  • What does this cell do? If you delete it, what changes?
  • Why this kernel size / threshold / pretrained model?
  • Which cell produced the number on this slide?
  • Double this parameter — which way does the result move, and why?
  • Why wasn't the more accurate solution the one you chose (or the other way round)?
